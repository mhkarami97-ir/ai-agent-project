بررسی دسترسی سایت

آزمون محدود از همین مرورگر؛ نتیجه هرگز تشخیص قطعی فیلترینگ، DNS یا IP نیست.

مرورگر نمی‌تواند DNS واقعی یا پاسخ HTTP سایت‌های دیگر را به‌علت CORS ببیند. درخواست no-cors فقط نشان می‌دهد مرورگر از این دستگاه توانست درخواست را آغاز کند؛ قطع اینترنت، CORS، VPN، افزونه و سرور همگی می‌توانند نتیجه را تغییر دهند.
